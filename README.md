# duckduckgo_async 🦆

![Python](https://img.shields.io/badge/python-3.10+-blue.svg)
![httpx](https://img.shields.io/badge/httpx-0.27.0+-green.svg)
![BeautifulSoup4](https://img.shields.io/badge/bs4-4.12.0+-green.svg)

**duckduckgo_async** — это легкая и быстрая асинхронная библиотека для парсинга поисковой системы DuckDuckGo. Она позволяет искать текст (с поддержкой пагинации) и изображения, не требуя официального API-ключа.

Библиотека использует `httpx` с поддержкой HTTP/2 для быстрых асинхронных запросов и `BeautifulSoup4` для аккуратного парсинга HTML-выдачи.

## ✨ Особенности

- **Полная асинхронность**: Построена на базе `httpx` и `asyncio`.
- **Поиск текста**: Удобный поиск по веб-страницам с поддержкой перехода по страницам (пагинация).
- **Поиск картинок**: Получение прямых ссылок на изображения в высоком качестве (включая обход защиты с помощью `vqd` токенов).
- **Строгая типизация**: Ответы возвращаются в виде удобных `dataclasses`.
- **Контекстный менеджер**: Безопасное управление сессиями запросов.

## 🚀 Быстрый старт

Основной способ работы с библиотекой — использование контекстного менеджера `AsyncDDG`. Это гарантирует правильное открытие и закрытие HTTP-сессии.

Вот базовый пример, демонстрирующий текстовый поиск и поиск картинок:

```python
import asyncio
from ddg_async import AsyncDDG

async def main():
    async with AsyncDDG() as ddg:
        # 1. Текстовый поиск (например, получение результатов со 2-й страницы)
        print("--- Текстовый поиск ---")
        text_results = await ddg.search_text("python async", page=2)
        for result in text_results[:3]:  # Выведем первые 3 результата
            print(f"Заголовок: {result.title}")
            print(f"Ссылка: {result.url}")
            print(f"Описание: {result.body}\n")

        # 2. Поиск картинок
        print("--- Поиск картинок ---")
        image_results = await ddg.search_images("капибара")
        for img in image_results[:3]:
            print(f"Название: {img.title}")
            print(f"Прямая ссылка: {img.image}\n")

if __name__ == "__main__":
    asyncio.run(main())
```

## 📚 Документация API

### Основной класс `AsyncDDG`

Точка входа для всех запросов. Рекомендуется использовать через `async with`.

#### `await search_text(query: str, page: int = 1) -> list[SearchResult]`
Ищет текстовые результаты (веб-страницы).
- `query` (str): Ваш поисковый запрос.
- `page` (int, по умолчанию 1): Номер страницы для пагинации.
- **Возвращает**: Список объектов `SearchResult`.

#### `await search_images(query: str) -> list[ImageResult]`
Ищет изображения. Автоматически получает и обрабатывает защитный токен `vqd`.
- `query` (str): Ваш поисковый запрос.
- **Возвращает**: Список объектов `ImageResult`.

### Модели данных (Dataclasses)

Все результаты возвращаются в виде структурированных объектов.

**`SearchResult`**
- `title` (str): Заголовок страницы.
- `url` (str): Очищенная прямая ссылка на сайт (без редиректов DDG).
- `body` (str): Краткое описание (сниппет) из поиска.

**`ImageResult`**
- `title` (str): Название изображения.
- `image` (str): Прямая ссылка на исходное изображение.
- `url` (str): Ссылка на страницу, где было найдено изображение.
- `source` (str): Источник (поисковая система/сайт).

### Обработка ошибок

Библиотека предоставляет кастомные классы исключений (в модуле `exceptions.py`):
- `DDGError`: Базовый класс для всех ошибок библиотеки.
- `DDGTokenError`: Выбрасывается, если DuckDuckGo заблокировал запрос или не удалось получить токен `vqd` (например, из-за бана IP или изменений в API).

